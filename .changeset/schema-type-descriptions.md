Show prop types and schema vendors in inspection details using schema metadata without validating values. Recognize Zod JSON Schema metadata, Valibot structures, ArkType expressions, and React adapter type names. Unsupported schemas display `unknown`.

Expose `schemaTypeNameSymbol` from the adapter factory package so predicate schemas can retain readable React type names. Devtools search also matches schema vendors.
