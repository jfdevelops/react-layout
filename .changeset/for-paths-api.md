Add the `forPaths` API on created resource configs: `createGetComponent(path)`, `forPaths(...)`, `isSubResourceKey`, and `subResources`. Paths support `$resource` / `$subResource` / `$component` variables with a builder for `addPathParams`, `addComponentKeyParams`, `addParams`, `render`, `setDisplayName`, and `asHOF`.
