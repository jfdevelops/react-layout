Show an icon for each render state in the devtools tree, graph, node details and state override buttons. Built-in `default`, `Loading`, `Error` and `NotFound` states get their own icons, colored from the chip palette; custom states get a generic icon. The Loading icon spins while that state is active or forced, unless the user prefers reduced motion.
