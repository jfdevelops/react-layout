A lookup requests a component slot that is missing or cannot be resolved.

## Identify the error

The error code is `invalidComponent`. This class belongs to the `ReactLayoutError` hierarchy.

## Resolve the error

Configure the requested slot, or choose one of the available component names.

## Release scope

This page describes `@jfdevelops/react-layout@4.1.0`. The behavior is based on the error definitions and their call sites in [the tagged source](https://github.com/jfdevelops/react-layout/blob/%40jfdevelops%2Freact-layout%404.1.0/packages/core/src/errors/invalid-component.ts).
