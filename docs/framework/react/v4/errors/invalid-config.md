A component lookup receives a configuration that is not an object.

## Identify the error

The error code is `invalidConfig`. This class belongs to the `ReactLayoutError` hierarchy.

## Resolve the error

Pass the resource configuration object returned by your config builder.

## Release scope

This page describes `@jfdevelops/react-layout@4.1.0`. The behavior is based on the error definitions and their call sites in [the tagged source](https://github.com/jfdevelops/react-layout/blob/%40jfdevelops%2Freact-layout%404.1.0/packages/core/src/errors/invalid-config.ts).
