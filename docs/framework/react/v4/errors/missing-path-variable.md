Resolving a path needs a $variable that was not supplied.

## Identify the error

The error code is `missingPathVariable`. This class belongs to the `ReactLayoutError` hierarchy.

## Resolve the error

Supply the variable when building or resolving the path.

## Release scope

This page describes `@jfdevelops/react-layout@4.1.0`. The behavior is based on the error definitions and their call sites in [the tagged source](https://github.com/jfdevelops/react-layout/blob/%40jfdevelops%2Freact-layout%404.1.0/packages/core/src/errors/missing-path-variable.ts).
