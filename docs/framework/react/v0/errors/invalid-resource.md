A resource lookup or path resolution requests an unknown resource.

## Identify the error

The error code is `invalidResource`. This class belongs to the `ReactLayoutError` hierarchy.

## Resolve the error

Use a resource declared in the layout configuration.

## Release scope

This page describes `@jfdevelops/react-layout@0.25.0`. Earlier 0.x releases can differ. The behavior is based on the error definitions and their call sites in [the tagged source](https://github.com/jfdevelops/react-layout/blob/%40jfdevelops%2Freact-layout%400.25.0/packages/core/src/errors/invalid-resource.ts).
