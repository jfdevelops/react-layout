A naming convention receives a part that it has not declared.

## Identify the error

The error code is `invalidPart`. This class belongs to the `ReactLayoutError` hierarchy.

## Resolve the error

Use a declared part; inspect context.validParts.

## Release scope

This page describes `@jfdevelops/react-layout@3.3.0`. The behavior is based on the error definitions and their call sites in [the tagged source](https://github.com/jfdevelops/react-layout/blob/%40jfdevelops%2Freact-layout%403.3.0/packages/core/src/errors/invalid-part.ts).
