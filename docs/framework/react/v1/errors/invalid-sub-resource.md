A nested lookup requests an unknown sub-resource or supplies an invalid sub-resource value.

## Identify the error

The error code is `invalidSubResource`. This class belongs to the `ReactLayoutError` hierarchy.

## Resolve the error

Use a sub-resource declared beneath the selected resource.

## Release scope

This page describes `@jfdevelops/react-layout@1.6.1`. The behavior is based on the error definitions and their call sites in [the tagged source](https://github.com/jfdevelops/react-layout/blob/%40jfdevelops%2Freact-layout%401.6.1/packages/core/src/errors/invalid-sub-resource.ts).
