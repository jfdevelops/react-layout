A resource lookup or path resolution requests an unknown resource.

## Identify the error

The error code is `invalidResource`. This class belongs to the `ReactLayoutError` hierarchy.

## Resolve the error

Use a resource declared in the layout configuration.

## Release scope

This page describes `@jfdevelops/react-layout@1.6.1`. The behavior is based on the error definitions and their call sites in [the tagged source](https://github.com/jfdevelops/react-layout/blob/%40jfdevelops%2Freact-layout%401.6.1/packages/core/src/errors/invalid-resource.ts).
